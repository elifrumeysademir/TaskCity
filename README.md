# TaskCity: Oyunlaştırılmış Görev Yönetim Sistemi

Kullanıcıların görevlerini tamamladıkça sanal bir şehir inşa ettiği,
dinamik sıralama sistemi içeren gamification tabanlı bir web uygulaması.

<br>

## Proje Hakkında

TaskCity, kullanıcı motivasyonunu artırmak amacıyla geliştirilmiş
oyunlaştırılmış bir görev yönetim sistemidir. Her tamamlanan görev,
kullanıcının sanal şehrinde bir bina katına dönüşür. Şehri en büyük
olan kullanıcı sıralamada birinci olur.


<br>

## Özellikler

- Kullanıcı kayıt ve güvenli giriş sistemi
- Görev oluşturma, tamamlama ve takip
- Tamamlanan görevlere göre sanal şehir büyümesi
- Dinamik kullanıcı sıralaması
- REST API mimarisi ile tam dokümantasyon
- Postman koleksiyonu ile uçtan uca test senaryoları

<br>

## Teknolojiler

`Java` `Spring Boot` `REST API` `Maven` `Postman` `SQL`
